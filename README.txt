Deskripsi:
Website ini adalah portofolio pribadi yang menampilkan informasi tentang saya, karya-karya terbaru, dan cara menghubungi saya. Dibangun menggunakan HTML, CSS, dan Bootstrap 5 untuk tampilan yang responsif dan modern.

Fitur Utama:
- Halaman Utama: Menampilkan profil singkat dan highlight portofolio
- Tentang Saya: Berisi informasi detail tentang latar belakang dan pengalaman
- Portofolio: Menampilkan proyek-proyek yang pernah dikerjakan
- Kontak: Formulir dan informasi kontak untuk menghubungi saya

Teknologi yang Digunakan:
- HTML5
- CSS3
- Bootstrap 5.3.8

Struktur File:
- index.html                : Halaman utama
- about.html                : Halaman tentang saya
- portofolio.html           : Halaman portofolio
- kontak.html               : Halaman kontak
- custom.css                : File CSS kustom
- /bootstrap-5.3.8-dist/    : Direktori Bootstrap
- /images/                  : Berisi gambar-gambar yang digunakan

Cara Menjalankan:
1. Buka file index.html di browser web favorit Anda
2. Gunakan menu navigasi untuk menjelajahi berbagai bagian website
